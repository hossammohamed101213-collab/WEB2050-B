# WEB2050 — موقع إدارة الحملات الإعلانية (خليجي · عربي/إنجليزي)

موقع من **ملف واحد** (`index.html`) بتصميم داكن ثلاثي الأبعاد: خلفية حيّة تتحول (كرة ← مجرة ← مخ)، بطاقات خدمات تتراص، لوحة تقارير بعملاء، باقات، نموذج طلب، قسم دعم وشكاوى، تقييمات، وفوتر بالصفحات القانونية. لا يحتاج تثبيت ولا خادم ولا بناء.

## الملفات

| الملف | وظيفته |
|---|---|
| `docs/index.html` | الموقع كله (HTML + CSS + JavaScript في ملف واحد) — المنشور على GitHub Pages |
| `MASTER_PROMPT.md` | الأمر الشامل لإنشاء نفس الموقع من الصفر أو تحويله لنشاط آخر |
| `docs/.nojekyll` | يجعل GitHub Pages يعرض الملف كما هو |
| `.gitignore` | ملفات يتجاهلها Git |

## التشغيل على جهازك

1. فك الضغط.
2. افتح `index.html` بالضغط المزدوج (Chrome أو Edge أو Safari).
3. يلزم اتصال بالإنترنت، لأن الخطوط والمكتبات (three.js وGSAP) تُحمَّل من الإنترنت.

## الرفع على GitHub ثم نشره مجانًا

**من المتصفح (بدون أوامر):**
1. ادخل github.com ← زر **New repository** ← الاسم `web2050` ← **Create repository**.
2. اضغط **uploading an existing file** ← اسحب الملفات من داخل المجلد المفكوك (وليس الملف المضغوط نفسه) ← **Commit changes**.
3. من **Settings ← Pages** اختر **Deploy from a branch** ← الفرع `main` والمجلد `/docs` ← **Save**.
4. بعد دقيقة يظهر رابط الموقع أعلى الصفحة نفسها (يكون بالشكل `https://اسمك.github.io/web2050/`).

**بالأوامر:**
```bash
cd web2050
git init && git add . && git commit -m "WEB2050 site"
git branch -M main
git remote add origin https://github.com/اسمك/web2050.git
git push -u origin main
```
الاستضافة على GitHub Pages مجانية للمستودعات العامة، وفي الخاصة تتطلب خطة مدفوعة، فتأكد قبل اختيار «Private».

## أين أعدّل؟ (ابحث في `index.html` بالكلمة)

| ما تريد تغييره | ابحث عن |
|---|---|
| رقم واتساب (الروابط كلها) | `WA_NUM` |
| الرقم المعروض في الفوتر وزر النسخ | `+971 56 737 1542` و `+971567371542` |
| أوقات العمل | `ftHrs` (مرتان: عربي وإنجليزي) |
| روابط التواصل الاجتماعي | `class="soon"` ← ضع الرابط في `href` وأزل `soon` |
| الألوان | `:root{` في أول ملف الـCSS |
| نصوص الصفحات القانونية | `var LEGAL` |
| أسماء الباقات ومزاياها | `data-plan=` |
| ترجمة إنجليزية لأي نص | القاموس `EN` (المفتاح نفسه الموجود في `data-i="..."`) |
| أوقات الرد في قسم الدعم | `tm1` و `pnD` |
| بريد التواصل | غير موجود حاليًا؛ أضفه في عمود «تواصل» في الفوتر |

قاعدة الترجمة: كل نص له `data-i="مفتاح"`. العربية تُقرأ من الصفحة نفسها، والإنجليزية من القاموس `EN`. عند إضافة نص جديد أضف المفتاح في الاثنين.

## ما يعمل وما يحتاج ربطًا لاحقًا

**يعمل الآن بدون أي خدمة:** الواجهة كلها، اللغتان، نموذج الطلب (يجهّز رسالة واتساب ترسلها أنت)، الشكاوى (تجهّز رسالة واتساب وكودًا)، التقييمات وعملاء لوحة التقارير والنشرة (تُحفظ في متصفح الزائر فقط).

**لا يعمل بعد (يحتاج خادم أو خدمة):**
- لوحة تحكم حقيقية ترى فيها التقييمات والشكاوى من كل الزوار.
- إرسال النشرة البريدية فعليًا.
- تتبّع حالة الشكوى بين الأجهزة.
- بيانات لوحة التقارير الحقيقية: الأرقام الموجودة **توضيحية** ومكتوب ذلك في الصفحة. ولا تضف أرقامًا مُختلقة كأنها نتائج عملاء.

## قواعد الموقع (حافظ عليها عند التعديل)

- الدفع خارج الموقع، وميزانية الإعلان منفصلة عن أتعاب الإدارة. لا بوابة دفع ولا خصم تلقائي.
- لا وعود بمبيعات أو أرباح أو زيارات مضمونة.
- لا عملاء ولا تقييمات ولا نتائج سابقة مختلقة.
- النصوص القانونية مسودات وتحتاج مراجعة محامٍ قبل الإطلاق.
- أوقات العمل وأوقات الرد التزامات أمام العميل: ضعها بما تستطيع الوفاء به فعلًا.
